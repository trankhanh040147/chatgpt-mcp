## Observability E2E (WIP — **not in PR #15**)

Local uncommitted: `scripts/e2e-attach-observability.ts`, `npm run e2e:attach-observability`.

Session runs (2026-09-01 evening) failed `CHIP_MISMATCH` with ~14 DOM chips. **Root cause discovered:** ChatGPT account **upload quota banner**:

> *"You've added all your available file uploads until 8:12 PM. Upgrade for more"*

This explains post-quota failures (not worker bug). Script updated to detect quota banner → `UPLOAD_QUOTA_EXCEEDED`.

Reports: `logs/attach-observability-{taskId}.json`

**Re-run benchmark after quota reset** (after 8:12 PM local) or different account.
