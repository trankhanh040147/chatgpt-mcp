# CI/CD — implementation plan

**Status:** ACTIVE (implemented in PR `feat/cicd`)  
**ADR:** [ADR-004](../decisions/ADR-004-cicd-architecture.md)

## Workflows

| File | Purpose |
|------|---------|
| `ci.yml` | Quality (Node 24) + Compat (Node 22.14) |
| `dependency-review.yml` | Block PRs introducing HIGH+ vulns |
| `release.yml` | Tag → prepare artifact → publish (OIDC) |
| `security.yml` | Weekly npm audit (non-blocking) |
| `live-e2e.yml` | Manual self-hosted Mac E2E |

## Manual setup (post-merge)

1. **Branch protection** — require: Quality, Compat, dependency-review, CodeQL
2. **Actions policy** — require SHA pinning
3. **CodeQL** — Settings → Security → Default setup
4. **Environment `npm`** — required reviewer, tags `v*.*.*`
5. **npm Trusted Publishing** — workflow `release.yml`, environment `npm`
6. **Self-hosted runner** — dedicated Mac, labels `self-hosted`, `macOS`, `chatgpt-mcp-live`

## Local commands

```bash
npm run verify
npm pack && npm run package:smoke
```

## Release flow

```bash
npm version X.Y.Z --no-git-tag-version
git commit -am "chore: release vX.Y.Z"
git tag vX.Y.Z && git push origin main && git push origin vX.Y.Z
```
