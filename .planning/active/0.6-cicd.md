# CI/CD — implementation plan

**Status:** ACTIVE · **ADR:** [ADR-004](../decisions/ADR-004-cicd-architecture.md)

## Workflows

| File | Trigger | Purpose |
|------|---------|---------|
| `ci.yml` | PR / push main | Quality (Node 24) + Compat (Node 22.14) |
| `dependency-review.yml` | PR | Block new HIGH+ vulns |
| `release.yml` | **workflow_dispatch** | E2E gate → bump → tag → pack → approval → publish |
| `security.yml` | weekly | npm audit (non-blocking) |
| `live-e2e.yml` | workflow_dispatch | Manual E2E on trusted ref |

## Release (no manual tag)

Actions → **Release** → choose `patch` / `minor` / `major` → Live E2E on self-hosted Mac → version commit + tag → package smoke → Environment `npm` approval → publish.

Do **not** push tags manually.

## Local commands

```bash
npm run check:unit
npm run verify
npm pack && npm run package:smoke
```

## Handoff zip

`make handoff-zip` includes: `.github`, `package-lock.json`, `LICENSE`, `config/`, etc.

## Manual setup (post-merge)

Branch protection, SHA pinning policy, CodeQL Default Setup, Environment `npm`, npm Trusted Publishing (`release.yml`), dedicated Mac runner.
