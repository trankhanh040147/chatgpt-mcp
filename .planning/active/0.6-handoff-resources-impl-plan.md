## Phase B — Attachment primitive

| Task | Detail |
|------|--------|
| `composer-attach.ts` | `input[type=file]` + `setInputFiles(snapshotPaths)` first; menu fallback |
| Before/after chips | `before = readChips()` → upload → `after = readChips()` |
| Verify | `added = multisetDiff(after, before)` equals expected displayName multiset |
| `PrepareResult` | Include `retryable` on failure ([ADR-006](../decisions/ADR-006-attachment-cleanup-retry.md)) |
| Cleanup API | `cleanup()` + `isClean()` on `ResourceDeliveryTarget` |
| Matcher tests | `scripts/test-attachment-match.ts` — multiset + truncation cases |

```ts
interface ResourceDeliveryTarget {
  prepare(files: readonly HandoffTaskFile[]): Promise<PrepareResult>;
  cleanup(): Promise<void>;
  isClean(): Promise<boolean>;
}

type PrepareFailure = {
  ok: false;
  expected: string[];
  observed: string[];
  added?: string[];
  reason: PrepareFailureReason;
  retryable: boolean;
};
```

**Observability (no content paths):**

```text
RESOURCE_PREPARE_STARTED  taskId fileId displayName sizeBytes sha256
RESOURCE_ATTACHED
RESOURCE_VERIFIED
RESOURCE_PREPARE_FAILED   reason retryable
```

Never log: `snapshotPath`, file body, workspace absolute paths.

## Phase C — Delivery state machine

Read [ADR-004](../decisions/ADR-004-dispatch-fence-vs-attachment.md), [ADR-006](../decisions/ADR-006-attachment-cleanup-retry.md), [ADR-007](../decisions/ADR-007-delivery-state-machine.md).

```ts
withUiWrite:
  result = await transport.prepare(files)

  if (!result.ok) {
    await transport.cleanup()
    if (!(await transport.isClean())) failHard()
    if (result.retryable) markDispatchFailed → requeue
    else fail task
    return
  }

  // POINT OF NO RETURN
  markDispatchStarted()
  await submitTaskId()
```

| Failure | retryable | After cleanup |
|---------|-----------|---------------|
| INPUT_NOT_FOUND | true | requeue if clean |
| UPLOAD_TIMEOUT | true | requeue if clean |
| CHIP_MISMATCH | true | requeue if clean |
| UPLOAD_REJECTED | false | fail |

No retry after fence. No retry if `!isClean()`.

Files: `src/transport/`, `src/browser/worker.ts`, `chatgpt.ts`

## Phase D — E2E

Script: `scripts/e2e-files-attach.ts`

### D1 — Happy path (distinct nonces)

```text
a.ts → ATTACH_E2E_NONCE_A
b.ts → ATTACH_E2E_NONCE_B

prompt: Return both nonces. Do not call handoff_read_file.

assert: A and B in result
```

### D2 — Partial upload failure

Simulate or inject B failure (test hook / controlled timeout).

Assert:

```text
TASK_ID not sent
dispatch_started_at unset
cleanup ran; composer clean (or task failed hard)
```

### D3 — Text-only regression

```text
files = []
→ no attach path
→ TASK_ID dispatched normally
```

### D4 — MCP read forbidden (production proof)

Native attach scenarios: result must not depend on `handoff_read_file` invocation.
