## 1. Ship bar (locked)

| Item | Decision |
|------|----------|
| Production transport | **Native CDP attachment required** |
| MCP lazy read sufficient? | **No** |
| Silent attach → MCP fallback? | **Forbidden** |
| File limits | **10 × 256KB, 1MB/task** |
| Create-time secret scan | **P0** |
| Duplicate basenames | **Reject at create** |
| Attach | **`input[type=file]` first**; menu fallback |
| Chip verify | **Per expected file** |
| E2E | **Native-only nonce**; no `handoff_read_file` for pass |

## 3. Key interfaces

```ts
type PrepareResult =
  | { ok: true; attached: PreparedResource[] }
  | {
      ok: false;
      expected: string[];
      observed: string[];
      reason:
        | "INPUT_NOT_FOUND"
        | "UPLOAD_TIMEOUT"
        | "CHIP_MISMATCH"
        | "UPLOAD_REJECTED";
    };
```

```ts
// Worker target ordering
withUiWrite:
  prepared = await transport.prepare(files)
  if (!prepared.ok) → markDispatchFailed (requeue)
  markDispatchStarted()
  submitTaskId()
```

## 4. E2E (native-only)

```ts
export const ATTACH_E2E_NONCE = "native_attach_7F4D92A1";
```

- ≥2 files, distinct basenames, nonce in file body
- Prompt: return nonce; **do not call handoff_read_file**
- Pass = result contains nonce + attach verified (MCP read not used for proof)
