# 0.7 — Handoff Resources

**Status:** SHIPPED (pending merge) · **Lifecycle:** SHIP-BAR

**Depends on:** v0.6 Worker Ops (CONSENT / URL recovery)

## Goal

Agent selects files → validate refs at create → **dispatch-time materialize** → runtime **guarantees delivery** via native CDP attachment.

**Principle:** Agent chooses context; runtime chooses transport.

**Contracts:**

- **Semantic:** workspace bytes at **dispatch** (not immutable snapshot at create)
- **Production delivery:** native CDP buffer upload (not MCP pull, not raw paths)
- **`handoff_read_file`:** disabled for tasks with attached files (Option C)

No silent attach → MCP fallback.

## Architecture

```text
handoff_create_task(files[])
  → registerTaskResourcePaths (cheap validation)
  → persist TaskResource refs + workspace_root

worker dispatch:
  materializeWorkspaceResources → PreparedResource[] (RAM)
  → setInputFiles(buffer) → verify chips → cleanup on fail
  DISPATCH_STARTED      ← point of no return
  TASK_ID_SENT
```
