# 0.6 — Handoff Resources

**Status:** ACTIVE · **Lifecycle:** SHIP-BAR  
**Impl plan:** [0.6-handoff-resources-impl-plan.md](./0.6-handoff-resources-impl-plan.md)  
**Review:** APPROVE WITH CHANGES (2026-08-29)

## Goal

Agent selects files → validate + snapshot → runtime **guarantees delivery** via native attachment.

**Principle:** Agent chooses context; runtime chooses transport.

**Contracts:**

- **Semantic:** immutable snapshot at create
- **Production delivery:** native CDP attachment (not MCP pull, not ZIP)

No silent attach → MCP fallback. **`handoff_read_file` stays** as secondary capability / future transports.

## Architecture

```text
handoff_create_task(files[])
  → validate + secret-content guard + snapshot
  → manifest

worker:
  PREPARING_RESOURCES
    → before chips → upload → after chips
    → verify added-chip multiset == expected
    → on fail: cleanup → isClean? → retry or fail
  RESOURCES_VERIFIED
  DISPATCH_STARTED      ← point of no return
  TASK_ID_SENT
```

ADRs: [004](../decisions/ADR-004-dispatch-fence-vs-attachment.md) · [006](../decisions/ADR-006-attachment-cleanup-retry.md) · [007](../decisions/ADR-007-delivery-state-machine.md)

## Data model

Public: `files?: string[]`. Internal: `HandoffTaskFile` with `snapshotPath`, `sha256`, etc.

**Duplicate basenames:** reject at create (`FILES_DUPLICATE_BASENAME`).

## Secret-content guard (create)

Best-effort detection of known patterns (`SECRET_PATTERNS`) — **not a DLP boundary**.

```text
match → FILES_SECRET_DETECTED → reject whole create
```

Read-time sanitize remains for MCP path.

## Limits

`10 files · 256 KB/file · 1 MB/task · text/code` — no bump in v0.6.

## P0 amendments (review)

1. **Cleanup before retry** — `cleanup()` + `isClean()`; no blind requeue
2. **Retryable vs permanent** — `retryable` on `PrepareFailure`; `UPLOAD_REJECTED` → fail
3. **Added-chip multiset verify** — not `expected ⊆ all chips`
4. **E2E** — distinct nonce per file; partial failure; text-only regression

## Chip verification (Phase B)

```text
before = readChips()
upload snapshotPaths
after = readChips()
added = multisetDiff(after, before)
assert multisetEqual(added.names, expected.names)
```

## PrepareResult

Failures include `retryable`, optional `added` chip names. See impl plan.

## E2E (Phase D)

| Scenario | Assert |
|----------|--------|
| Happy | `NONCE_A` + `NONCE_B` in result; no MCP read |
| Partial fail | No TASK_ID; no fence; cleanup |
| Text-only | No attach; normal dispatch |
